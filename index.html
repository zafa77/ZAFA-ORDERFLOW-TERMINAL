TYPOLOGY

PROFILE PROPORTION

Auto scale = mean + selected standard deviations of visible row sizes. Manual value is in the selected input unit.

DATA SETTINGS

Public trades are aggregated by price and taker side over 100 ms. MBO is unavailable; trade count means aggregate events.

TICK GROUPING

Higher factor = wider price buckets and generally fewer occupied rows. With Readable rows ON, factor 5 starts at the readable minimum; every increase widens the grouping. Applies without changing chart zoom.Display tick is a 0.01 USDT calculation unit, not a claim about exchange tick-size rules. Grouping affects Footprint only.

PLOT SETTINGS

When enabled, auto grouping grows from the readable minimum; manual grouping uses a minimum row height of 18 pixels or text height + 6. Disable for exact manual ticks.Auto compact stacks Bid (top) and Ask (bottom) in narrow columns. Volume abbreviations: m = 0.001, µ = 0.000001. Hover for precise values. At extreme zoom out, profiles remain visible even when text cannot fit.

POC / VALUE AREA

POC and value area use total selected input (Buy + Sell), after trade filters.

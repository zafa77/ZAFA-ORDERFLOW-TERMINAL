# Security policy

ZAFA is a development-stage browser-based market analysis and simulation platform.
Do not place exchange credentials, passwords, access tokens or personal data in
this public repository. Do not report sensitive details in public issues.

Report security problems privately to the repository owner via GitHub private
vulnerability reporting if enabled. A dedicated verified security/privacy contact
must be published before public account registration; until that is configured,
do not send confidential details through public channels.

Scope: frontend, account data isolation, future Supabase Edge Function and
deployment configuration. The public preview has no authentication or cloud sync.
Please include reproducible non-sensitive steps and version, avoid probing other
users' accounts or accessing data without authorization.

See [deployment and GDPR launch runbook](SECURITY-LAUNCH.md).

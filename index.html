TYPOLOGY

PROFILE PROPORTION

Auto scale = mean + selected standard deviations of visible row sizes. Manual value is in the selected input unit.

DATA SETTINGS

Binance Spot public trades are executions, not individual resting orders. MBO is unavailable.

TICK GROUPING

Higher factor = wider price buckets and fewer footprint rows. Lower factor = more detail. 70 = standard density. Applies at the current zoom.Display tick is a 0.01 USDT calculation unit, not a claim about exchange tick-size rules. Grouping affects Footprint only.

PLOT SETTINGS

When enabled, grouping uses at least the text height + 4 pixels, even with small manual ticks. Disable for exact manual grouping.Numbers appear when there is enough space. Use chart zoom manually; settings do not change the viewport.

POC / VALUE AREA

POC and value area use total selected input (Buy + Sell), after trade filters.
